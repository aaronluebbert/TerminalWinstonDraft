winston draft sim, written in python, all by hand by me

python is the only prerequisite

to play, download your favorite cube from cubecobra in .csv file format, move it to the same directory as the winstonDraft.py, and rename it to cardList.csv

Lastly, run winstonDraft.py

deck lists will be saved to text files so you can export them to your favorite deck building website

have fun!
